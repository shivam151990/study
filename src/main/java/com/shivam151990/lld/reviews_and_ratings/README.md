Product Reviews and Ratings

1. addReview(userId, productId, rating 1–5, text). A user may review a product only once.
2. getAverageRating(productId)
3. getTopProducts(n) returns the top n by average rating, requiring at least 3 reviews.
4. updateRating and deleteRating keep the average correct.
5. getReviews(productId) newest first.
